# fzf-find.nvim - make :find fast
Simple FZF upgrade for :find in Neovim.

### Requirements
* Neovim 0.11+
* fd
* fzf

### Install
[**lazy.vim**](https://github.com/folke/lazy.nvim)
```lua
{ 'colehdlr/fzf-find' }
```

[**vim.pack**](https://neovim.io/doc/user/pack/)
```lua
vim.pack.add({ 'https://github.com/colehdlr/fzf-find' })
```

[**vim-plug**](https://github.com/junegunn/vim-plug)
```lua
Plug 'colehdlr/fzf-find'
```

### Usage
Just use :find as you normally would!
